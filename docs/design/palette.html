Стайл-гайд VTT

Визуальная система для виртуального стола в эстетике тёмного средневекового фэнтези. Настроение задано мудбордом: глубокий тёплый чёрный, благородное золото, приглушённый вино-красный. Типографика — Spectral (Франция) и Montserrat (Аргентина) в болгарском начертании кириллицы. Клик по HEX копирует значение.

Типографика

Две пары «серьёзный serif + геометричный sans». Страница объявлена с lang="bg" — это включает OpenType-фичу locl, и оба шрифта подставляют болгарские альтернаты для кириллицы (к, ж, д, т, в с прямыми штрихами и иной геометрией). Выглядит строже и уникальнее обычной русской кириллицы.

Background / Surface

Слои тёмного фона. Чем выше элемент в иерархии интерфейса (модалка, всплывашка), тем светлее его поверхность — это создаёт ощущение глубины без использования теней.

--vtt-bg-base

#0E0B08

Самый нижний слой. Фон канваса карты, заливка страницы. Не использовать под длинный текст — слишком глубокий.

--vtt-bg-surface

#1A1510

Основные панели UI. Боковая панель чата, список инициативы, шит персонажа — всё, что «лежит» на фоне карты.

--vtt-bg-elevated

#241C15

Плавающие поверхности. Модалки, всплывающие меню, тултипы действий, открытая карточка монстра поверх панели.

--vtt-bg-sunken

#07050A

Утопленные области. Ячейки инвентаря, подложка HP-бара, лог событий — всё, куда элементы «вдавлены».

Инициатива

Панель поверх карты — заметная граница, но без контраста с фоном.

Border / Divider

Границы тоже тёплые, не серые — это ключ к стилю. Золотая окантовка используется экономно: рамка карты боя, активная панель, декоративные углы.

--vtt-border-subtle

#2E251C

Внутренние разделители. Строки в таблице инициативы, разделение секций в шите персонажа.

--vtt-border-strong

#4A3A28

Рамки панелей. Внешние границы крупных блоков UI, граница input'а в фокусе.

--vtt-border-gold

#8C6A3A

Декоративная золотая окантовка. Только для значимого: рамка карты, активный ход, важная модалка. Не злоупотреблять.

Accent — золото

Главный бренд-акцент. Золотой — это действия игрока, активные состояния, заголовки. На тёмном фоне читается как «важно» и «благородно», поэтому используйте строго для значимых элементов.

--vtt-accent

#D4A857

Основной акцент. Главная кнопка «Бросить», индикатор активного хода, выделение выбранного токена.

--vtt-accent-soft

#E4C9A0

Мягкий тёплый. Крупные заголовки (serif), имя персонажа, hover-состояние текстовых ссылок.

--vtt-accent-deep

#8C6A3A

Приглушённый акцент. Eyebrow-лейблы (моно-капс), неактивная вкладка, обводка золотой кнопки.

Danger / Красный империи

Приглушённый вино-красный из мудборда. Используется не только для ошибок — это цвет здоровья, врагов, агрессивных действий. Яркая версия — только для критических состояний.

--vtt-danger

#792B3B

Основной красный. HP-бар, маркер враждебного NPC, кнопка «Удалить», атакующее действие.

--vtt-danger-bright

#B23B4F

Критическая подсветка. Мигание при критическом HP, текст крит-урона в логе. Экономно, чтобы сохранить силу сигнала.

--vtt-danger-soft

#3A1820

Фон уведомлений об ошибке. Подложка инлайн-ошибки валидации, заливка чипа danger.

Критический урон

Semantic — игровая логика

Отдельные оттенки для лечения, предупреждений и подсказок. Все три намеренно приглушены и уведены в тёплую/холодную пыль, чтобы не конфликтовать с золотым и красным — палитра остаётся цельной.

--vtt-success

#6B8E4E

Успех, лечение. Зелёные цифры исцеления в логе, удачный бросок навыка, кнопка «Готов» в лобби.

--vtt-warning

#C08A3E

Предостережение. Истекающие эффекты (осталось 1 раунд), низкий HP (< 50%), несохранённые изменения. Близко к золоту — не ставить рядом с accent.

--vtt-info

#5A7A8E

Нейтральная информация. Тултипы с правилами, системные сообщения в чате, подсказки мастеру.

Text / Нейтрали

Тёплый off-white вместо чистого белого — иначе текст «вылетает» из палитры. Иерархия через три уровня приглушённости, плюс инверсный для текста на золоте.

--vtt-text-primary

#E4C9A0

Основной текст. Весь body, параграфы, значения статов. Тёплый, слегка золотистый — не использовать #FFF.

--vtt-text-secondary

#B6A893

Вторичный текст. Описания предметов, контекст в тултипах, лейблы полей формы.

--vtt-text-muted

#858484

Подписи и disabled. Таймстемпы в чате, неактивные кнопки, служебные значения (HEX, ID).

--vtt-text-inverse

#0E0B08

Текст на светлом. Только для контента поверх `--vtt-accent` (золотая кнопка) или поверх соломенного hover-фона.

Геометрия и эффекты

UI максимально сдержан. Плоские поверхности, тонкие границы, скромные радиусы, строгая 4-кратная сетка. «Магия» не живёт в кнопках — она живёт в атмосфере сцены: тёплом свете на карте, frosted-glass модалках поверх мира, виньетке по краям. Интерфейс уходит в тень, чтобы приключение вышло вперёд.

Радиусы

Мелкие для UI-элементов (кнопки, инпуты) — хранят медиевальную точность. Крупные (--r-lg+) только для магических карточек и модалок.

Frosted glass

Для всплывающих слоёв поверх карты: модалки, оверлеи действий, тултипы над токенами. backdrop-filter: blur(14px) + полупрозрачный тёплый фон. Даёт ощущение, что интерфейс «плывёт» над сценой.

Заклинание: Огненный шар

Ambient light · свет костра

Радиальные градиенты в тёплых тонах + виньетка по краям. Главный фокус получает «свет», края уходят в темноту. На карте боя — свет исходит от активного токена, факела, алтаря. Это и есть «магия без декораций».

Компоненты

Плоско, строго, типографика ведёт. Золотая заливка появляется только на одной ключевой кнопке в контексте; всё остальное — тёмные поверхности, тихие границы, акценты через цвет текста.

Кнопки

Плоские, без градиентов. Primary — тёмная с золотым текстом. Сплошная золотая заливка (btn-hero) — только для одного ключевого действия в контексте.

Поля и управление

Утопленные поля (shadow-inset) — ощущение «выгравировано». Focus-ring мягкий, золотой.

Артефакт · редкий

Свиток воскрешения

Однократное применение. Требует компонента: бриллиант стоимостью не менее 500 зм. Восстанавливает жизнь существу, погибшему не более 10 дней назад.

Токены на карте

Прямоугольные со скруглением — строже и современнее круглых. Активный ход отмечен тонким золотым кольцом, враг — красной границей. Значок в углу — инициатива.
