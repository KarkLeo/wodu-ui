StatusChip

Атом для «производных» показателей — урон оружия, броня, монеты, инициатива, скорость. В отличие от StatChip, значение здесь вычисляется из других сущностей (экипировки, заклинаний) и не бросается само по себе. Главная сила — tooltip/popover с breakdown'ом: «d6 оружие + d2 бафф = итого d6+d2» или «2 панцирь + 1 щит = 3». Это заменяет текущие help-modal с толстой рамкой.

1. Три основных варианта

Базовая раскладка: label сверху · значение по центру · подпись снизу. Символ-иконка — опционален, он подсказывает категорию (оружие, щит, монета) и помогает сканировать шапку периферийным зрением.

5. Popover · разложение значения

Breakdown-row — один паттерн на три сущности. Грид 1fr auto: слева имя + источник, справа вклад. Для урона это бонусы-строчки, для брони — элементы экипировки, для монет — последние транзакции. Одна разметка, разный контент.

Hero-кнопка условна. У урона — «Бросить» (hero-golden). У брони — не нужна (броня не бросается, а используется как число в защите). У монет — ghost «+ Записать транзакцию» для ручной корректировки.
