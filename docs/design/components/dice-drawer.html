Dice Drawer · Журнал

Глобальная панель справа — общая для всего приложения, не привязана к конкретному персонажу или вкладке. Раньше здесь оседали только броски; теперь это единый фид «что происходило с персонажем» — броски, урон и лечение, опыт и уровень, характеристики, инвентарь, экипировка, магия. В шапке — тумблер Броски · Изменения · Всё. Классический VTT-паттерн: лента снизу, newest-at-bottom, автопрокрутка к свежей записи. В свернутом состоянии — узкий рейл с последним результатом.

1. DiceRow · строка истории

Один атом лога. Левая иконка — тип броска (кубик / капля для урона). В центре — мета (источник, время) и формула с расшифровкой бросков. Справа — крупный результат в чипе. Состояния кодируют цветом результата, а не лейблом.

2. LogRow · строка изменения листа

Тот же ритм, что у DiceRow: иконка → мета → суть → чип справа. Вместо формулы — короткая фраза («Боевой меч», «Кольчуга надета», «Уровень 3»). Вместо результата — дельта с единицей (HP, XP, с, брн). Цвет кодирует знак: красный — потеря, зелёный — восстановление, золото — прогресс.

3. Quick-roll chips · наборы кубиков

Стандартные кубики одним тапом. 2d6 подсвечена — это основной бросок системы. Остальные кубики — для общих бросков и гомбрюшки, когда мастер скажет «d20 на восприятие».

7. В контексте приложения

Как панель садится поверх основного экрана. Слева — контент вкладки (лист персонажа, каталог, магия — не важно). Справа — рейл или раскрытая панель. Когда панель свёрнута, поверх основного контента висит FAB с бейджиком нового броска (для быстрого раскрытия, если игрок не видит рейл).

8. Правила отображения

Короткая памятка о том, как панель ведёт себя.

Порядок

Newest-at-bottom. Автопрокрутка к свежему броску, если пользователь уже внизу; иначе появляется кнопка «↓ 3 новых» (не показана — deferред).

Группировка

Разделители по дням: «Сегодня», «Вчера», далее абсолютная дата. Разделитель сам по себе — только eyebrow-текст с decorative-линией.

Состояния результата

Крит (макс на всех кубиках) — золото + glow. Провал (≤6 на 2d6) — приглушённый красный. Остальное — нейтральный чип.

Источник броска

В meta-строке: ярлык (ВЫН, Урон, Ручной), опционально — имя персонажа и контекст (оружие, навык), время. Всё через тонкие точки.

Очистка

Кнопка «корзина» в шапке — очищает весь лог (с confirm'ом). История персистится локально (localStorage) — не привязана к конкретному чару.

Ограничение

В памяти держим последние 200 записей (броски + изменения суммарно). Старше — обрезаются молча. Для тейблтоп-сессии этого хватает на целый вечер.

Фильтр

Sticky-тумблер Броски · Изменения · Всё под шапкой. Разделители дней считаются по видимому срезу — если в день ничего нет, разделитель скрывается. Состояние фильтра сохраняется локально.

Типы изменений

Здоровье (урон / лечение), Опыт, Уровень, Характеристики, Инвентарь (+ / − / сломано), Монета (+ / −), Экипировка (надето / снято), Магия (ритуалы / заклинания / ртуть). Каждый тип — своя иконка и цвет дельты.

Действия vs. просмотр

Быстрые кубики и поле формулы всегда видны и активны — даже на фильтре «Изменения». Фильтр управляет только лентой, а не возможностью бросить.
