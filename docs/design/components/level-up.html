Flow · Level-up wizard

LevelUp

Когда XP перешагнул порог, шапка показывает алерт «Готов к повышению уровня!». По нажатию открывается визард в том же cc-shell, что и создание персонажа — топбар, степпер, контент, футер. Шаги: Навык → Способность → Стат → Кости → Итог. Те, для которых нет награды на данном уровне, помечаются в степпере как is-skipped (пунктир). Всё работает на существующих примитивах cc-*.

§1

Триггер — алерт в шапке

Блок появляется над XP-баром, когда isReadyToLevelUp(char) возвращает true. Один btn-hero «Повысить ↑» ведёт в визард.

§2

Степпер — состояния шагов

Тот же cc-stepper из character-creation.html, только 4 точки вместо 3 и добавлено состояние is-skipped — пунктирная точка для наград, которых нет на текущем уровне. Итоговый экран — отдельный пятый шаг, не в степпере (это финальный просмотр).

§3

Шаг 1 · Навык

Все навыки, которых ещё нет у персонажа, в виде cc-abil-строк. Выбранный — с золотой галочкой в cc-check. Категория справа как cc-abil-flag.

§4

Шаг 2 · Способность

Та же cc-abil-строка, описание — cc-abil-desc прямо под именем. Тексты короткие (обычно 1 строка), поэтому ничего не скрываем — аккордеон тут лишний. Спецэффекты (sturdy, summoning) маркируются цветным cc-abil-chip справа.

§5

Шаг 3 · Прибавка к стату

Тот же 3×2 грид cc-attr, что и при создании персонажа. Справа от модификатора — превью → +M. Стат на +3 — :disabled + красная подпись «на максимуме».

§6

Шаг 4 · Кости HP

Всегда последний активный шаг. Бросается hitDice + 1 костей, сохраняются верхние targetLevel. Перебрасывать можно сколько угодно. Итог заменяет maxHp целиком.

§7

Шаг 5 · Подтверждение

Список всех наград в одном cc-section. Авто-эффекты (sturdy, damageBonusDice, summoning) получают lu-sum-pill «авто» / «откр.». Единственная кнопка — btn-hero «Подтвердить».

§8

Было / стало

Старый экран — плоский скролл со всеми шагами подряд, каждая опция в толстом бордере, кнопка «Принять» всегда внизу. Новый — те же cc-shell / cc-abil / cc-attr, что в мастере создания — общий визуальный язык.
