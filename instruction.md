
Необходимо сделать интерактивную страницу персонажа для настолькой игры Dungeon World

В папке ref/ находится сама страница. Нужно следовать всем деталям этой страницы. Ничего не должно быть искажено или отсуствовать. 

В папке mood/ находятся примеры для подражания визуального стиля, ее использовать для создания дизайна, нужно получить схожее настроение

Это должно быть приложение на VueJS 3 + TS.
Данные хратить в Local Storage. можна связывать через Pina
Для сложных контролов использовать Reka UI 

На текущий момент я вижу 3 варианта интерфейса
- создание персонажа
- персонаж в игре
- повышения уровня персонажа

Дизайн в результате должен быть максимально юзер френдли и лаконичным. Например все выборы которые относятся к созданию персонажа, после создания скрыты.
Нету каких-то лишних элементов в ui 

Список ходов выглядит как лист, который игрок может листать и выбирать из списка доступных.

Дизайн должен быть адаптирован для мобильных устройств

Для архитектуры использовать бест практис чтобы можно было прилджение куда-то интегрировать или расширить.
